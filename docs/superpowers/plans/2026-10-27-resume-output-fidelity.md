# Resume Output Fidelity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every fact in the candidate's source resume (roles, promotions, dates, bullets, skills, education, extra sections) reaches the generated client DOCX, in the right association, with review warnings when the system is unsure — without paid APIs and without lowering current visual quality.

**Architecture:** Keep the existing FastAPI pipeline (`generate.py` → `pdf_parser` → `detailed_resume_parser` → `structured_resume_store` → `document_from_store` → `docx_skeleton_service` / `_render_docx`). Fix the specific places that drop or merge content, make extraction order-correct for DOCX and multi-layout PDFs, capture unknown sections instead of discarding them, and add a mechanical source-vs-output coverage check that returns `passed` / `needs_review` / `failed`. No rewrite, no new infrastructure.

**Tech Stack:** Python 3.11, FastAPI, python-docx ≥1.1.2, PyMuPDF, pdfplumber, pytest. Optional: Tesseract (via PyMuPDF's built-in OCR hook). Next.js frontend (only a small change to show warnings).

## Global Constraints

- No paid parsing, OCR, or LLM services. Default workflow makes zero LLM calls.
- Bedrock stays optional; `RESUME_LLM_CONDENSE` and `RESUME_AGENT_PIPELINE` default to `false`.
- Faithful output is the default: no summarizing, no bullet/skill caps, no role removal to hit a page target.
- Never log resume text, candidate names, emails, or phones. Log counts and IDs only.
- Never commit real candidate documents. All new fixtures are synthetic and generated by script.
- Do not claim "100% verified". Statuses are `passed` (mechanical checks passed), `needs_review`, `failed`.
- Keep current client styling: Arial 10, name-only header, client logos/footer, Title Case headings.

## Why these changes (findings from the current code)

These are the concrete places where today's output loses or corrupts candidate data. Each task below fixes one or more of them.

| # | Location | What goes wrong |
|---|----------|-----------------|
| L1 | `resume_generation_service.py:794-820` | Long resumes go through `moderate_summarize_store` + `fit_store_to_pages` (drops bullets, cuts summary to 1800 chars, shortens bullets to 300 chars mid-sentence), then LLM "readable polish" runs by default (`RESUME_LLM_CONDENSE=True`). |
| L2 | `structured_resume_store.py:26-41,551-605` | `expand_to_bullets(max_bullets=20)` for roles and `16` for projects silently truncates. |
| L3 | `structured_resume_store.py:219` | Education `details[:2]` drops honours/coursework lines. |
| L4 | `resume_generation_service.py:1687-1705` (`_dedupe_experience_items`) | Any zero-bullet role at a company that has another role with bullets is deleted. This removes earlier promotions (e.g. "Engineer 2018–2020" listed above "Senior Engineer 2020–2023" at the same employer). |
| L5 | `docx_skeleton_service.py:150-159` | Skeleton renderer `continue`s on any experience item without bullets — same promotion loss on client templates. |
| L6 | `structured_resume_store.py:381-388` (`document_from_store`) | If the client `section_order` omits achievements/languages, those sections are never appended. There is no place at all for unknown sections (Publications, Volunteering, Training, Patents, Clients…). |
| L7 | `detailed_resume_parser.py:1550-1566` | Parser only extracts fixed keys. Content under an unrecognized heading is absorbed into the previous section (e.g. Publications bullets become experience bullets of the last job) or lost. |
| L8 | `pdf_parser.py:655-700` (`_extract_docx`) | All paragraphs first, then all tables → wrong order for table-based resumes; headers/footers ignored (contact info often lives there); text boxes ignored; merged cells repeated; nested tables ignored; hyperlink URLs lost. |
| L9 | `pdf_parser.py:21-77` (`_strip_repeated_header_footer`) | Lines repeated on most pages are removed from **every** page, including page 1 — candidate name/contact repeated as a page header disappears entirely. |
| L10 | `pdf_parser.py:420-528` | One column gutter per page. A full-width header + two columns + full-width section later on the same page reads incorrectly. |
| L11 | `pdf_parser.py` | PDF link annotations (LinkedIn/GitHub behind "LinkedIn" text) are not extracted. |
| L12 | `generate.py:115-124` | Scanned PDFs fail with a generic "no readable text" error; no OCR path. |
| L13 | `main.py:13-19` | CORS has no `expose_headers`, so the Vercel frontend cannot read `Content-Disposition` / `X-Saved-Format-Id` (and won't be able to read review warnings). |
| L14 | `resume_generation_service.py:91-97` | `candidate_name` logged on every request (PII). |

## Scope decisions

**In this plan (directly improves output):** L1–L14, synthetic regression fixtures, coverage/integrity report, small DOCX polish (keep-with-next, URL wrapping, no trailing blank page), template sample-data leak check.

**Deliberately deferred (does not improve output quality, or high cost for little gain now):**
- Durable job queue, worker leases, object-storage direct upload, moving the backend to Vercel. The current EC2 FastAPI + Vercel frontend split already isolates heavy processing.
- Docling layout backend. Revisit only if Task 6 fixtures still fail on real layouts; it pulls large models.
- Full typed IR with bounding boxes for every word. We add a minimal `SourceBlock` list (Task 4) — enough for ordering, provenance of section/source type, and coverage checks.
- Condensed mode UI. Existing condense code stays reachable via `RESUME_OUTPUT_MODE=condensed` but is not the default.

```python
def _pdf_lines(path: Path, pages: list[list[tuple[float, float, str, float]]]) -> Path:
    doc = fitz.open()
    for items in pages:
        page = doc.new_page(width=612, height=792)
        for x, y, text, size in items:
            page.insert_text((x, y), text, fontsize=size, fontname="helv")
    doc.save(path)
    doc.close()
    return path


def single_column_pdf(out: Path) -> Path:
    y = 60
    items = [(50, y, PERSON, 16)]
    for text in [EMAIL, PHONE, "", "EXPERIENCE"]:
        y += 18
        items.append((50, y, text, 10))
    for company, title, dates, bullets in PROMOTION_ROLES:
        y += 18
        items.append((50, y, f"{title} | {company} | {dates}", 10))
        for b in bullets:
            y += 14
            items.append((60, y, f"- {b}", 10))
    y += 24
    items += [(50, y, "EDUCATION", 10), (50, y + 14, "B.S. Computer Science, State University, 2015", 10)]
    return _pdf_lines(out / "single_column.pdf", [items])


def two_column_pdf(out: Path) -> Path:
    full = [(50, 50, PERSON, 16), (50, 68, f"{EMAIL} | {PHONE}", 10)]

    footer_full = [(50, 400, "PUBLICATIONS", 10), (50, 414, "Rivera J. Streaming joins at scale. 2022.", 10)]
    return _pdf_lines(out / "two_column.pdf", [full + left + right + footer_full])


def scanned_pdf(out: Path) -> Path:
    src = single_column_pdf(out)
    raster = fitz.open(src)
    pix = raster[0].get_pixmap(dpi=200)

    doc = fitz.open()
    page = doc.new_page(width=612, height=792)
    page.insert_image(page.rect, pixmap=pix)
    path = out / "scanned.pdf"
    doc.save(path)
    doc.close()
    return path
```

```python
from __future__ import annotations

import io
import os
import sys
import tempfile
from pathlib import Path

from app.services import resume_generation_service as rgs  # noqa: E402
from app.models.candidate import Candidate  # noqa: E402
from app.services.aptino_template import build_aptino_client_format  # noqa: E402
from app.services.pdf_parser import extract_text_from_document  # noqa: E402
from tests.fixtures.build_fixtures import build_all  # noqa: E402

rgs.upload_bytes_to_key = lambda **_: None


def docx_text(data: bytes) -> str:
    doc = Document(io.BytesIO(data))
    parts = [p.text for p in doc.paragraphs]
    for t in doc.tables:
        for row in t.rows:
            parts.extend(c.text for c in row.cells)
    return "\n".join(parts)


def main() -> None:
    out = Path(tempfile.mkdtemp())
    for key, path in build_all(out).items():
        if key == "template_with_sample":
            continue
        text = extract_text_from_document(str(path)) if path.suffix != ".pdf" or key != "scanned_pdf" else ""
        if not text.strip():
            print(f"{key:24} extract=EMPTY")
            continue
        cand = Candidate(name="x", resume_path=str(path), extracted_data={"raw_text": text, "resume_text": text})
        try:
            data = rgs.ResumeGenerationService().generate(cand, build_aptino_client_format("Client"))
        except Exception as exc:  # noqa: BLE001
            print(f"{key:24} FAILED {type(exc).__name__}")
            continue
        src_lines = {l.strip() for l in text.splitlines() if len(l.strip()) > 25}
        out_text = docx_text(data)
        kept = sum(1 for l in src_lines if l[:40] in out_text)
        print(f"{key:24} source_lines={len(src_lines):4} found_in_output={kept:4} ratio={kept / max(1, len(src_lines)):.2f}")


if __name__ == "__main__":
    main()
```

```python
# backend/app/services/source_blocks.py
from __future__ import annotations

from dataclasses import dataclass, field


@dataclass
class SourceBlock:
    id: str
    text: str
    origin: str
    page: int | None = None
    bbox: tuple[float, float, float, float] | None = None
    style: str | None = None
    is_list: bool = False
    bold: bool = False
    font_size: float | None = None
    links: list[str] = field(default_factory=list)


def blocks_to_text(blocks: list[SourceBlock]) -> str:
    lines: list[str] = []
    for block in blocks:
        text = block.text.strip()
        if not text:
            continue
        lines.append(f"• {text}" if block.is_list and not text.startswith(("•", "-", "*")) else text)
        for url in block.links:
            if url not in text:
                lines.append(url)
    return "\n".join(lines)
```

```python
# backend/app/services/docx_reader.py
"""Read DOCX content in true document order: headers, body paragraphs/tables (incl. nested), text boxes, footers."""
from __future__ import annotations

from docx import Document
from docx.oxml.ns import qn
from docx.table import Table
from docx.text.paragraph import Paragraph

from app.services.source_blocks import SourceBlock

_MAX_BLOCKS = 20_000


class _Ids:
    def __init__(self) -> None:
        self.n = 0

    def next(self) -> str:
        self.n += 1
        return f"b{self.n:05d}"


def _paragraph_block(p: Paragraph, origin: str, ids: _Ids) -> SourceBlock | None:
    text = p.text or ""
    textbox = " ".join(
        t.text or "" for t in p._p.iter(qn("w:t")) if _inside_textbox(t)
    ).strip()
    if textbox and textbox not in text:
        text = f"{text} {textbox}".strip()
    if not text.strip():
        return None
    links = [h.url for h in getattr(p, "hyperlinks", []) if getattr(h, "url", "")]
    style = p.style.name if p.style is not None else None
    is_list = p._p.pPr is not None and p._p.pPr.numPr is not None or bool(style and "List" in style)
    bold = bool(p.runs) and all(r.bold for r in p.runs if r.text.strip())
    sizes = [r.font.size.pt for r in p.runs if r.font.size is not None]
    return SourceBlock(ids.next(), text, origin, style=style, is_list=is_list, bold=bold,
                       font_size=max(sizes) if sizes else None, links=links)


def _inside_textbox(el) -> bool:
    parent = el.getparent()
    while parent is not None:
        if parent.tag == qn("w:txbxContent"):
            return True
        parent = parent.getparent()
    return False


def _table_blocks(table: Table, origin: str, ids: _Ids, out: list[SourceBlock]) -> None:
    for row in table.rows:
        seen: set[int] = set()
        cells: list[str] = []
        for cell in row.cells:
            key = id(cell._tc)
            if key in seen:  # horizontally merged cell repeats the same <w:tc>
                continue
            seen.add(key)
            for inner in cell._tc.iterchildren(qn("w:tbl")):
                _table_blocks(Table(inner, cell), origin, ids, out)
            text = "\n".join(p.text for p in cell.paragraphs if p.text.strip()).strip()
            if text:
                cells.append(text)
        if cells:
            out.append(SourceBlock(ids.next(), " | ".join(cells), "table"))


def _container_blocks(container, origin: str, ids: _Ids, out: list[SourceBlock]) -> None:
    for item in container.iter_inner_content():
        if isinstance(item, Paragraph):
            block = _paragraph_block(item, origin, ids)
            if block:
                out.append(block)
        elif isinstance(item, Table):
            _table_blocks(item, origin, ids, out)
        if len(out) > _MAX_BLOCKS:
            raise ValueError("DOCX exceeds block limit")


def read_docx_blocks(path: str) -> list[SourceBlock]:
    doc = Document(path)
    ids = _Ids()
    out: list[SourceBlock] = []
    seen_parts: set[int] = set()
    for section in doc.sections:
        for header in (section.first_page_header, section.header):
            if header.is_linked_to_previous or id(header.part) in seen_parts:
                continue
            seen_parts.add(id(header.part))
            _container_blocks(header, "header", ids, out)
    _container_blocks(doc, "body", ids, out)
    for section in doc.sections:
        for footer in (section.first_page_footer, section.footer):
            if footer.is_linked_to_previous or id(footer.part) in seen_parts:
                continue
            seen_parts.add(id(footer.part))
            _container_blocks(footer, "footer", ids, out)
    return out
```

```python
def _is_full_width(line: list, width: float) -> bool:
    x0 = min(float(w[0]) for w in line)
    x1 = max(float(w[2]) for w in line)

def _split_bands(lines: list[list], width: float) -> list[list[list]]:
    bands: list[list[list]] = []
    current: list[list] = []
    for line in lines:
        if line and _is_full_width(line, width):
            if current:
                bands.append(current)
                current = []
            bands.append([line])
            continue
        current.append(line)
    if current:
        bands.append(current)
    return bands
```

```python
# backend/app/services/pdf_ocr.py
from __future__ import annotations

import os
import shutil

from app.core.config import settings


class OcrUnavailableError(RuntimeError):
    """Raised when a page needs OCR but Tesseract is not installed/enabled."""


def ocr_available() -> bool:
    return bool(settings.RESUME_OCR_ENABLED) and shutil.which("tesseract") is not None and bool(
        os.environ.get("TESSDATA_PREFIX") or shutil.which("tesseract")
    )


def page_needs_ocr(page) -> bool:
    text = page.get_text("text") or ""
    letters = sum(c.isalpha() for c in text)
    printable_ratio = sum(c.isprintable() or c.isspace() for c in text) / max(1, len(text))
    cid_garbage = text.count("(cid:") + text.count("\ufffd")
    area = abs(page.rect)
    image_area = 0.0
    for info in page.get_image_info():
        x0, y0, x1, y1 = info["bbox"]
        image_area += max(0.0, x1 - x0) * max(0.0, y1 - y0)
    image_cover = min(1.0, image_area / area) if area else 0.0
    if letters < 30 and image_cover > 0.3:
        return True
    if cid_garbage > 20 or printable_ratio < 0.85:
        return True
    return image_cover > 0.6 and letters < 200


def ocr_page_text(page, dpi: int) -> str:
    tp = page.get_textpage_ocr(language=settings.RESUME_OCR_LANG, dpi=dpi, full=False)
    return page.get_text("text", textpage=tp) or ""
```

```python
# backend/app/services/output_integrity.py
from __future__ import annotations

import io
import re
from dataclasses import dataclass, field

from docx import Document


@dataclass
class IntegrityReport:
    status: str
    checks: dict[str, dict] = field(default_factory=dict)
    warnings: list[str] = field(default_factory=list)


def _norm(text: str) -> str:
    text = re.sub(r"[\u2013\u2014]", "-", str(text or "")).lower()
    return re.sub(r"[^a-z0-9]+", " ", text).strip()


def _docx_text(data: bytes) -> str:
    doc = Document(io.BytesIO(data))
    parts = [p.text for p in doc.paragraphs]
    for t in doc.tables:
        for row in t.rows:
            parts.extend(c.text for c in row.cells)
    return _norm("\n".join(parts))


def _check(name: str, expected: list[str], hay: str, checks: dict, warnings: list[str], label: str) -> None:
    items = [_norm(x) for x in expected if _norm(x)]
    missing = [x for x in items if x not in hay]
    checks[name] = {"ok": not missing, "expected": len(items), "found": len(items) - len(missing)}
    if missing:
        warnings.append(f"{len(missing)} of {len(items)} {label} from the source were not found in the output.")


def check_output_integrity(store: dict, docx_bytes: bytes, *, template_sample_text: str = "",
                           suppressed_sections: list[str] | None = None) -> IntegrityReport:
    try:
        hay = _docx_text(docx_bytes)
    except Exception:
        return IntegrityReport("failed", {}, ["The generated document could not be opened."])
    checks: dict[str, dict] = {}
    warnings: list[str] = []
    roles = [r for r in store.get("experience") or [] if isinstance(r, dict)]
    _check("companies", [r.get("company", "") for r in roles], hay, checks, warnings, "employers")
    _check("titles", [r.get("title", "") for r in roles], hay, checks, warnings, "job titles")
    _check("dates", [r.get("duration", "") for r in roles], hay, checks, warnings, "employment dates")
    _check("bullets", [b for r in roles for b in r.get("description") or []], hay, checks, warnings,
           "experience bullets")
    edu = [e for e in store.get("education") or [] if isinstance(e, dict)]
    _check("education", [e.get(k, "") for e in edu for k in ("degree", "institution", "year")], hay,
           checks, warnings, "education fields")
    skills = [s for vals in (store.get("skills_by_category") or {}).values() for s in vals or []]
    _check("skills", skills or store.get("skills") or [], hay, checks, warnings, "skills")
    for key, label in (("certifications", "certifications"), ("achievements", "achievements"),
                       ("languages", "languages")):
        _check(key, store.get(key) or [], hay, checks, warnings, label)
    extras = [s for s in store.get("additional_sections") or []
              if s.get("title") not in set(suppressed_sections or [])]
    _check("additional_sections", [l for s in extras for l in s.get("lines") or []], hay, checks, warnings,
           "lines from other sections")
    leaks = [_norm(l) for l in template_sample_text.splitlines() if len(_norm(l)) >= 8 and _norm(l) in hay]
    checks["template_leak"] = {"ok": not leaks, "expected": 0, "found": len(leaks)}
    if leaks:
        warnings.append(f"{len(leaks)} line(s) from the client template's sample resume appear in the output.")
    for title in suppressed_sections or []:
        warnings.append(f"Section '{title}' was omitted by client policy.")
    status = "passed" if all(c["ok"] for c in checks.values()) else "needs_review"
    return IntegrityReport(status, checks, warnings)
```

- If a `_check` fails only because the renderer reformatted a date (e.g. `Jul. 2021` → `Jul 2021`), fix the normalizer, not the check.
